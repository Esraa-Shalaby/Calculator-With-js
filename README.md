# 🧮 Simple Calculator

A clean, neon-styled calculator built with **HTML, CSS, and vanilla JavaScript**.

## ✨ Features

- ➕ Basic operations: addition, subtraction, multiplication, division
- 🔢 Decimal point support
- 🧹 "AC" button to clear the display instantly
- ⚠️ Graceful error handling — shows "error" for invalid expressions instead of crashing
- 🎨 Dark theme with a glowing pink/magenta accent (neon shadow effect)
- 📱 Fully responsive layout across tablet and mobile screens

## ⚙️ How It Works

- Each number/operator button appends its value to the display using `appanedToDisplay()`.
- Pressing **"="** evaluates the full expression and shows the result.
- If the expression is invalid, the calculator catches the error and displays `"error"` instead of breaking.
